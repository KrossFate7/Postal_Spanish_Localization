# POSTAL - Localización al Español Latino

---

## 📋 Descripción del Mod

Este proyecto es una traducción completa de la interfaz, menús, textos y subtítulos del juego **POSTAL** al **español latino** (aunque dice "Latino" se utilizo un Español Neutro). El objetivo principal es ofrecer una experiencia de localización natural, fluida y fiel al tono irreverente del título original para el público hispanohablante.

---

## 🚀 Características

* **Traducción adaptada:** Textos de menús, opciones, interfaz y elementos del juego localizados al español.
* **Respeto por el tono original:** Se mantiene la esencia satírica, oscura y bizarra del juego.
* **Fácil instalación:** Diseñado para integrarse sin complicaciones en la versión de PC.

---

## 📥 Instalación

1. Descarga el archivo comprimido más reciente desde la sección de **[Releases](../../releases)**.
2. Descomprime el contenido dentro de la carpeta de instalación principal de *POSTAL* (donde se encuentra el ejecutable del juego).
3. Sobrescribe los archivos cuando se te solicite (se recomienda hacer una copia de seguridad de los archivos originales).
4. ¡Inicia el juego y disfruta de la experiencia en español!
